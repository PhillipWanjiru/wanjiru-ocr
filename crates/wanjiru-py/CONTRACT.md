This file is the contract of the crate. A change to the public API, an invariant, an oracle, the budget or the dependency list changes this file in the same commit, and an ADR when the change is a decision.

## Purpose

A Python package over the facade with the same result types as the C ABI, built as wheels for the supported platforms.

## Public API

Planned. Nothing is stable until the exit check of the phase that implements the crate.

- `wanjiru.Engine`, `wanjiru.process(path_or_bytes, **options) -> Document`.
- Typed stubs shipped with the package.

## Invariants

1. The Python result converts to canonical DocIR JSON identical to the Rust one.
2. The GIL is released during processing.
3. Errors map to exceptions carrying the stable `WNJ-E` code.

## Oracles

What the crate is checked against, independently of its own tests:

- API parity tests against the C ABI; wheel install tests on a clean environment per platform.

## Budget

- Overhead of the binding over a direct call, recorded in `docs/budgets.md`.

## Unsafe policy

`#![forbid(unsafe_code)]` as long as the binding is generated by safe abstractions; if the binding generator needs unsafe, the crate becomes a zone by ADR.

## Allowed dependencies

Checked by `cargo xtask check-contracts` against `Cargo.toml` and against the layer rule.

- Workspace: `wanjiru-types`, `wanjiru-docir`, `wanjiru`
- External: none
- Planned external (needs an ADR and a row in `data/registry/licences.yaml` first): `pyo3` (MIT or Apache-2.0)

## Open questions

- `wanjiru-py -> wanjiru` is a same-layer dependency on the facade (ADR-011, Proposed).
