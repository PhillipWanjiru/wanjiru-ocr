# ADR-NNN: What was decided, in one sentence

| | |
|---|---|
| Status | Proposed |
| Date | YYYY-MM-DD |
| Phase | the phase in which this is decided, and the phase in which it takes effect |
| Supersedes | none |
| Enforced by | the check, file or gate that keeps this true; or "nothing yet" |

If the status is Proposed, say here what turns it into Accepted.

## Context

The forces: what the project needs, what constrains it, and what is known. Evidence with its source and
its limits. Facts, not preferences.

## Decision

What is decided, in numbered statements that a reviewer can check against the repository.

## Consequences

What gets better, what gets worse, what must now be done. Include the costs. Say what was measured and
what was only assumed.

## Alternatives considered

Each real alternative, and the reason it lost.

## Revisit when

Observable triggers that reopen the question.
