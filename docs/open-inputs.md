# Open inputs

Questions only the owner can answer. None of them blocks Phase 1; all of them shape later phases. When one is
answered, the decision goes into the ADR or contract it changes and its row is deleted here.

| Input | Shapes |
|---|---|
| Focused hours per week (the plan assumes 30) | the length of every phase |
| First operating system for users (development runs on x86-64 Linux) | packaging, the reference machine, the sandbox work of Phase 2 |
| Target market and locale pack | scripts, formats, which identity documents, the golden set |
| Document source and consent route | the golden set, the consent forms |
| Budget | people to key the golden set, hardware, legal advice |
| Licence and business model (Apache-2.0 is the default, ADR-009) | every outside component that can be used |
| The dedication, in the author's words | [DEDICATION.md](../DEDICATION.md) |

Also waiting for the owner are the four proposed ADRs: 003 (runtime trait), 009 (licence), 010 (CTC decoder) and
011 (same-layer exceptions). See [adr/README.md](adr/README.md).
